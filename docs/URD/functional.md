
## 1.Functional Requirements  
Functional អ្វីដែលអ្នកប្រើប្រាស់ត្រូវការឱ្យប្រព័ន្ធអាចធ្វើបាន។

 ### Functional User Requirement
### FR-01: Monitor Blood Glucose
ប្រព័ន្ធត្រូវអាចទទួល និងតាមដានទិន្នន័យកម្រិតជាតិស្ករពី Sensor។

### FR-02: Analyze Glucose Data
ប្រព័ន្ធត្រូវអាចវិភាគទិន្នន័យដើម្បីកំណត់ថាកម្រិតជាតិស្ករកំពុង
ឡើងចុះឬស្ថិតក្នុងកម្រិតធម្មតា។

### FR-03: Calculate Insulin Dose
ប្រព័ន្ធត្រូវអាចគណនាបរិមាណ Insulin ដោយផ្អែកលើទិន្នន័យ និងការកំណត់ដែលបានអនុញ្ញាត។

### FR-04: Deliver Insulin
ប្រព័ន្ធត្រូវអាចបញ្ជា Pump ឱ្យបញ្ចេញ Insulin តាមការកំណត់។

### FR-05: Generate Alarm
ប្រព័ន្ធត្រូវអាចបង្កើត សំឡេង និង/ឬការជូនដំណឹងលើអេក្រង់ នៅពេលរកឃើញស្ថានភាពមិនប្រក្រតី ដូចជា៖

* ជាតិស្ករខ្ពស់ ឬទាប
* Insulin ជិតអស់
* Battery ជិតអស់
* Sensor Error
* Pump Error ឬការស្ទះ
* FR-06: Display Information

### ព័ន្ធត្រូវបង្ហាញព័ត៌មានសំខាន់ៗ ដូចជា៖

* កម្រិតជាតិស្ករ
* ស្ថានភាព Pump
* ស្ថានភាព Battery
* ស្ថានភាព Insulin
* Alarm/Error

### FR-07: Detect System Faults
ប្រព័ន្ធត្រូវអាចរកឃើញកំហុសរបស់ Sensor, Pump, Battery និងផ្នែក Software។
