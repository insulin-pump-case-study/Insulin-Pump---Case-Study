## 1. Non-Functional Requirements 
បង្ហាញថា ប្រព័ន្ធត្រូវដំណើរការដោយមានគុណភាព និងលក្ខណៈបែបណា។

## NFR-01: Safety
ប្រព័ន្ធត្រូវផ្តល់អាទិភាពខ្ពស់ចំពោះសុវត្ថិភាព និងត្រូវមានវិធានការការពារការផ្តល់ Insulin ខុស។

## NFR-02: Reliability
ប្រព័ន្ធត្រូវដំណើរការបានមានស្ថេរភាព និងអាចទុកចិត្តបាន។

## NFR-03: Accuracy
ការវាស់ទិន្នន័យ និងការគណនាត្រូវមានភាពត្រឹមត្រូវខ្ពស់។

## NFR-04: Availability
ប្រព័ន្ធត្រូវអាចដំណើរការ និងប្រើប្រាស់បាននៅពេលអ្នកជំងឺត្រូវការ។

## NFR-05: Usability
ឧបករណ៍ និង User Interface ត្រូវងាយស្រួលសម្រាប់អ្នកជំងឺប្រើប្រាស់។

## NFR-06: Response Time
ប្រព័ន្ធត្រូវឆ្លើយតបទៅនឹងការផ្លាស់ប្តូរ ឬស្ថានភាពគ្រោះថ្នាក់ក្នុងពេលសមស្រប។

## NFR-07: Security
ប្រព័ន្ធត្រូវការពារទិន្នន័យ និងការកែប្រែការកំណត់ដោយអ្នកដែលគ្មានសិទ្ធិ។
